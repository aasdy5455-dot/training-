# 🧮 Scientific Calculator | Python OOP

A simple command-line scientific calculator built with **Python** using **Object-Oriented Programming (OOP)** principles.

This project provides basic arithmetic operations and scientific mathematical functions with calculation history and error handling.

## ✨ Features

- Basic arithmetic operations:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (*)
  - Division (/)
- Power and Square Root
- Trigonometric functions:
  - Sine (Sin)
  - Cosine (Cos)
  - Tangent (Tan)
- Logarithmic functions:
  - Log (Base 10)
  - Natural Log (Ln)
- Factorial calculation
- Calculation history
- Error handling for invalid operations
- Degree-based trigonometric calculations

## 🛠️ Technologies

- Python 3
- Math Module
- Object-Oriented Programming (OOP)

## 📖 OOP Concepts Used

This project demonstrates several Object-Oriented Programming concepts:

- **Classes:** `ScientificCalculator` and `CalculatorApp`
- **Objects:** Creating calculator instances
- **Constructors:** Initializing objects using `__init__()`
- **Methods:** Implementing mathematical operations
- **Encapsulation:** Managing calculation history inside the calculator object
- **Exception Handling:** Handling mathematical errors and invalid inputs
